1. Documentación y referencia oficial🔗

Organismos, fundaciones, especificaciones y manuales técnicos de referencia.

  • OSGeo — Open Source Geospatial Foundation — Fundación que agrupa y da soporte a los principales proyectos geoespaciales libres.
  • OGC — Open Geospatial Consortium — Organización internacional que define los estándares abiertos de interoperabilidad geoespacial.
  • Instituto Geográfico Nacional (IGN España) — Organismo oficial responsable de geodesia, cartografía oficial, nivelación y redes GNSS en España.
  • Centro Nacional de Información Geográfica (CNIG) — Centro de descargas y difusión de datos geográficos oficiales de España.
  • Documentación oficial de QGIS — Manuales de usuario, guías de formación y documentación de PyQGIS.
  • Documentación de GDAL/OGR — Librería de referencia para lectura, transformación y escritura de datos ráster y vectoriales.
  • PROJ — Transformaciones de coordenadas — Biblioteca base para conversiones y transformaciones de sistemas de referencia de coordenadas.
  • Referencia de funciones PostGIS — Documentación oficial de las funciones SQL espaciales (ST_*) y operadores de PostGIS.
  • Cloud-Native Geospatial Guide — Guía de referencia sobre la arquitectura y formatos geoespaciales optimizados para la nube.

2. Estándares, formatos y servicios web🔗

Especificaciones de formatos de datos, sistemas de referencia y protocolos de intercambio geoespacial.

Formatos vectoriales🔗

  • GeoJSON — Formato de intercambio geoespacial abierto basado en JSON (IETF, RFC 7946).
  • GeoPackage — Contenedor abierto y ligero basado en SQLite para almacenar datos vectoriales y ráster (OGC).
  • FlatGeobuf — Formato binario de alto rendimiento basado en FlatBuffers para streaming y acceso espacial indexado (cloud-native).
  • GeoParquet — Formato columnar binario optimizado para analítica geoespacial masiva sobre Apache Parquet.
  • Vector Tiles (MVT) — Especificación binaria de teselas vectoriales para renderizado web eficiente por GPU (Mapbox / de facto).
  • Shapefile — Formato clásico multiactivo de Esri para geometría y atributos (estándar de facto).
  • GML — Geography Markup Language: codificación XML para modelar y transportar entidades geográficas (OGC/ISO).
  • KML — Keyhole Markup Language: gramática XML para visualización en globos virtuales y visualizadores (OGC).
  • WKT / WKB — Well-Known Text y Well-Known Binary para representación textual y binaria de geometrías (OGC/ISO).

Formatos ráster y multidimensionales🔗

  • GeoTIFF — Formato TIFF extendido con metadatos de georreferenciación (OGC).
  • Cloud Optimized GeoTIFF (COG) — GeoTIFF organizado internamente en teselas y pirámides para lectura por rangos HTTP en la nube.
  • NetCDF — Formato autodescriptivo para matrices y datos científicos multidimensionales (Unidata).
  • Zarr — Formato de almacenamiento de arrays N-dimensionales comprimidos en bloques particionados (OGC Community Standard).

Nubes de puntos y 3D🔗

  • LAS/LAZ — Formato binario estándar para el intercambio de datos LiDAR y su variante comprimida LAZ (ASPRS).
  • COPC — Cloud Optimized Point Cloud: nube de puntos LAS/LAZ estructurada espacialmente para streaming en la nube.
  • 3D Tiles — Especificación para streaming y renderizado jerárquico (LOD) de modelos 3D, mallas, nubes de puntos y Gaussian/Triangle Splats mediante glTF (OGC).
  • glTF / KHR_gaussian_splatting — Estándar de transmisión de escenas 3D (glTF 2.0) y extensión oficial para splatting y radiometría.

Servicios web OGC clásicos🔗

  • WMS — Web Map Service: solicitud de imágenes de mapa prerrenderizadas georreferenciadas.
  • WMTS — Web Map Tile Service: servicio de teselas de imagen de mapa en cuadrículas predefinidas.
  • TMS — Tile Map Service: especificación de la OSGeo para servicio de teselas mediante estructura de URLs predecibles.
  • WFS — Web Feature Service: consulta y descarga de datos vectoriales a nivel de entidad/geometría.
  • WCS — Web Coverage Service: acceso a datos ráster brutos y coberturas multidimensionales con sus valores numéricos.
  • CSW — Catalogue Service for the Web: publicación y consulta de catálogos de metadatos geoespaciales.
  • WPS — Web Processing Service: ejecución de procesos y análisis espaciales en remoto.
  • SOS — Sensor Observation Service: consulta e intercambio de observaciones y lecturas de sensores.

OGC APIs y catálogos modernos🔗

  • OGC APIs — Familia modular de estándares RESTful basados en OpenAPI y JSON (Features, Tiles, Maps, Coverages, Processes, Records).
  • STAC — SpatioTemporal Asset Catalog — Especificación comunitaria moderna para catalogar, buscar e indexar imágenes de satélite y datos de observación.

Sistemas de referencia y metadatos🔗

  • EPSG — Registro oficial y autoritativo de sistemas de referencia de coordenadas (CRS), elipsoides, datums y transformaciones.
  • WKT-CRS (ISO 19162) — Estándar para la representación textual de sistemas de referencia de coordenadas.
  • ISO 19115 — Estándar internacional que define el esquema de metadatos para la información geográfica.
  • INSPIRE — Directiva europea que establece las normas para la Infraestructura de Información Espacial en la UE.

3. Software SIG, topografía y 3D🔗

Aplicaciones de escritorio, herramientas de campo y suites de procesado técnico.

SIG de escritorio🔗

  • QGIS — El Sistema de Información Geográfica de escritorio de referencia en el mundo de código abierto.
  • GRASS GIS — SIG avanzado con potente motor de modelado espacial, análisis ráster y vectorial.
  • SAGA GIS — SIG orientado al análisis geocientífico, geomorfometría y modelos digitales del terreno (MDT).
  • gvSIG Desktop — SIG de escritorio libre con amplia trayectoria y fuerte comunidad hispanohablante.
  • WhiteboxTools — Plataforma de geoprocesamiento de alto rendimiento para análisis geoespacial, hidrológico y de relieve.
  • Orfeo ToolBox (OTB) — Suite para procesado digital de imágenes de teledetección (clasificación, segmentación y ortorrectificación).
  • Marble — Globo virtual y atlas interactivo de escritorio (KDE), ideal para docencia y visualización.
  • GeoLibre — Plataforma SIG ligera y cloud-native que corre en navegador, escritorio, móvil y Jupyter para visualizar, explorar y analizar datos geoespaciales (MapLibre GL JS, DuckDB-WASM, deck.gl).
  • RustGIS — SIG rápido y de código abierto escrito en Rust puro para cartografía, análisis y compartición de datos geoespaciales (escritorio y navegador web).

Trabajo de campo y movilidad🔗

  • QField — Aplicación móvil para Android e iOS basada en el motor de QGIS para toma de datos y edición en campo.
  • Mergin Maps — Plataforma de captura y sincronización colaborativa de datos de campo integrada con QGIS.

Geodesia, GNSS y topografía🔗

  • RTKLIB — Paquete de programas para posicionamiento GNSS de precisión (RTK, DGPS, PPP) de código abierto.
  • RTKLIB-EX (demo5) — Fork mantenido de RTKLIB, optimizado para receptores GNSS de bajo coste y constelaciones modernas.
  • GNSS-SDR — Receptor GNSS de radio definida por software (SDR) multiconstelación y multifrecuencia.
  • Ginan — Toolkit de procesamiento GNSS de alta precisión (PPP, órbitas, relojes y troposfera) de Geoscience Australia.
  • Anubis — Herramienta para control de calidad, análisis y preprocesado de ficheros RINEX (versiones 2, 3 y 4).
  • GNU Gama — Ajuste riguroso de redes geodésicas y topográficas 1D, 2D y 3D por mínimos cuadrados.
  • Emlid RTK Docs — Guías y documentación práctica sobre flujos de trabajo con receptores GNSS RTK/PPK.

Fotogrametría, LiDAR y mallas 3D🔗

  • OpenDroneMap (ODM / WebODM) — Ecosistema completo para fotogrametría con drones (ortomosaicos, modelos 3D y nubes de puntos).
  • COLMAP — Pipeline y suite de Structure-from-Motion (SfM incremental y global GLOMAP) con Multi-View Stereo (MVS) de alta precisión.
  • CloudCompare — Software de referencia para visualización, edición, registro y comparación de nubes de puntos 3D y mallas.
  • MeshLab — Sistema avanzado de procesamiento, filtrado, limpieza, inspección y renderizado de mallas 3D y nubes de puntos.
  • Meshroom (AliceVision) — Suite de reconstrucción 3D fotogramétrica basada en pipelines nodales de Structure-from-Motion.
  • Regard3D — Programa de fotogrametría de escritorio con interfaz gráfica intuitiva basado en OpenMVG/OpenMVS.
  • PDAL — Point Data Abstraction Library — Librería y suite CLI para filtrado, conversión y procesado de nubes de puntos LiDAR.
  • LAStools (open components) — Herramientas para manipulación y compresión de datos LiDAR en formato LAS/LAZ.
  • Entwine — Indexador y generador de pirámides octree para nubes de puntos masivas (base de EPT/COPC).
  • e-foto — Estación fotogramétrica digital completa (GPL) orientada a la enseñanza e investigación.
  • PerfectTIN — Herramienta para convertir nubes de puntos en mallas de triángulos irregulares (TIN).
  • Hugin — Software de ensamblado panorámico con calibración de parámetros ópticos y corrección de distorsión de lentes.
  • Triangle Splatting — Representación de campos de radiancia (radiance fields) mediante microtriángulos; optimizada para renderizado en tiempo real y compatibilidad directa con mallas poligonales y motores gráficos.
  • nerfstudio — Framework modular para reconstrucción 3D y renderizado volumétrico mediante NeRF, 3D Gaussian Splatting (3DGS) y exportación a mallas/splats.
  • 3D Tiles Tools — Utilidades oficiales de Cesium para optimizar, validar y convertir conjuntos de datos 3D Tiles.
  • obj23dtiles — Conversor de modelos 3D (OBJ, glTF, GLB) a 3D Tiles (b3dm / tileset.json) con optimización de cajas envolventes (bounding boxes) y LOD.
  • Recursos y generadores de 3D Tiles — Catálogo curado de herramientas para generar tilesets 3D Tiles.

Calibración de cámaras y visión por computador🔗

  • mrcal — Toolkit del NASA JPL para calibración rigurosa de cámaras, modelado de incertidumbre y optimización fotogramétrica.
  • Kalibr — Toolbox del ETH Zurich para calibración precisa intrínseca/extrínseca multicámara y sincronización visual-inercial (cámara-IMU).
  • Camodocal — Calibración para modelos de cámara omnidireccionales, gran angular y ojos de pez (fisheye).
  • AprilTag — Sistema de dianas y marcadores visuales fiduciales para calibración de alta precisión, orientación y seguimiento.

Entornos y distribuciones preparadas🔗

  • OSGeoLive — Distribución Linux en vivo (Lubuntu) con todo el stack de software geoespacial preinstalado y configurado.
  • OSGeo4W — Instalador modular para Windows de paquetes OSGeo (QGIS, GDAL/OGR, GRASS, Python...).

4. Bases de datos, servidores y backend geoespacial🔗

Infraestructura backend para almacenamiento, consulta, publicación y geoprocesamiento de datos espaciales.

Bases de datos espaciales🔗

  • PostGIS — Extensión espacial para PostgreSQL; el motor de base de datos relacional geoespacial de referencia.
  • SpatiaLite — Extensión que añade capacidades espaciales a SQLite; base de datos ligera en un único archivo.
  • DuckDB (extensión spatial) — Base de datos OLAP embebida de alto rendimiento con soporte vectorial y ráster.
  • MobilityDB — Extensión de PostGIS/PostgreSQL para la gestión de objetos móviles, trayectorias y series temporales.
  • rasdaman — Motor de base de datos y servidor de análisis para cubos de datos ráster multidimensionales masivos.

Servidores de mapas, datos y APIs🔗

  • GeoServer — Servidor de datos geoespaciales en Java de referencia; implementa WMS, WFS, WCS, WMTS y OGC APIs.
  • MapServer — Servidor de mapas en C/C++ reconocido por su alta velocidad, bajo consumo y estabilidad.
  • pygeoapi — Servidor geoespacial en Python que implementa los estándares RESTful de la familia OGC APIs.
  • QGIS Server — Servidor que publica proyectos .qgz de QGIS como servicios web estándar (WMS, WFS, OGC API).
  • deegree — Framework Java para servicios web OGC e infraestructuras de datos espaciales corporativas.
  • pgRouting — Extensión de PostGIS para análisis de rutas, caminos mínimos y problemas de grafos espaciales.

Servidores de teselas y optimización en nube🔗

  • Martin — Servidor de teselas vectoriales y ráster ultrarrápido escrito en Rust (PostGIS, MBTiles, PMTiles).
  • pg_tileserv — Servidor ligero en Go para servir teselas vectoriales MVT directamente desde funciones y tablas de PostGIS.
  • TiTiler — Servidor dinámico en Python para generación y visualización de teselas a partir de formatos COG, STAC y Zarr.
  • GeoWebCache — Servidor de caché y aceleración de teselas para servicios WMS/WMTS.
  • VersaTiles — Formato de archivo único y servidor de teselas vectoriales de alto rendimiento sin dependencias pesadas.

Servidores de geoprocesamiento🔗

  • ZOO-Project — Plataforma de geoprocesos de código abierto compatible con WPS y OGC API - Processes con soporte multilenguaje.
  • PyWPS — Servidor en Python para la publicación y ejecución remota de algoritmos de geoprocesado vía OGC WPS.
  • actinia — API REST de geoprocesado en la nube de alto rendimiento impulsada por el motor de GRASS GIS.

Catálogos y plataformas integrales🔗

  • GeoNetwork — Plataforma de catálogo de metadatos espaciales (CSW, ISO 19115/19139, DCAT) para IDEs.
  • GeoNode — Sistema de gestión de contenidos (CMS) geoespacial para compartir mapas, capas y datos colaborativos.
  • Giswater — Plataforma libre para la gestión de redes de abastecimiento, saneamiento y drenaje urbano sobre PostGIS y EPANET/SWMM.
  • GeoHealthCheck — Aplicación de monitorización de disponibilidad, rendimiento y calidad de servicios web OGC.

5. Cartografía web, visualizadores y movilidad🔗

Librerías cliente para la creación de mapas interactivos en el navegador, motores de enrutamiento y herramientas de estilos.

Visualizadores y clientes de mapas web🔗

  • Leaflet — Librería JavaScript ligera, modular y amigable para mapas interactivos 2D.
  • OpenLayers — Librería JavaScript avanzada y completa para cartografía web con soporte de proyecciones, vectoriales y ráster.
  • MapLibre GL — Motor de mapas vectoriales por GPU para web (JS) y móvil (iOS/Android), fork comunitario y libre de Mapbox GL.
  • API-IDEE — API oficial del IGN-CNIG para crear visualizadores web interoperables con capas de la IDEE de España.
  • CesiumJS — Motor de visualización 3D geoespacial para globos terráqueos interactivos y visualización de 3D Tiles en el navegador.
  • iTowns — Framework 3D/2D del IGN francés sobre Three.js para visualización de datos espaciales masivos.
  • Terria.js — Framework para construir portales y visualizadores de datos espaciales complejos sobre CesiumJS y Leaflet.
  • MapStore — Plataforma WebGIS modular para crear geoportales y paneles de control sin programar.
  • GeoMoose — Framework ligero para portales cartográficos basados en OpenLayers.
  • Mapbender — Framework en PHP/Symfony para administrar y publicar geoportales seguros.

Geocodificación, rutas y herramientas de OSM🔗

  • Nominatim — Motor de geocodificación directa e inversa basado en datos de OpenStreetMap.
  • Photon — Geocodificador de autocompletado rápido tolerante a erratas basado en Elasticsearch y OSM (Komoot).
  • OSRM (Open Source Routing Machine) — Motor de cálculo de rutas y matrices de distancia ultrarrápido en C++ sobre OpenStreetMap.
  • Valhalla — Motor de enrutamiento multimodal de código abierto (vehículo, bicicleta, peatón, transporte público).
  • osm2pgsql — Herramienta esencial para importar y transformar datos de OpenStreetMap a bases de datos PostgreSQL/PostGIS.
  • Overpass API — API de consulta y extracción de subconjuntos específicos de datos de OpenStreetMap.

Generación de teselas y editores de estilos🔗

  • Maputnik — Editor visual de hojas de estilo JSON para MapLibre GL y Mapbox GL.
  • Tippecanoe — Herramienta CLI de referencia para generar teselas vectoriales multiescala a partir de GeoJSON masivo.
  • Planetiler — Generador en Java capaz de crear un fichero MBTiles planetario completo a partir de OpenStreetMap en pocas horas.
  • OpenMapTiles — Conjunto de esquemas abiertos y herramientas para generar teselas de base cartográfica mundial.
  • Spreet — Generador de sprites y atlas de iconos para estilos de MapLibre GL a partir de archivos SVG.
  • Charites — Herramienta para diseñar y validar estilos de mapas en formato YAML legible.
  • MapLibre Style Spec — Especificación técnica del formato JSON de estilos cartográficos vectoriales.

6. Ecosistema de librerías de desarrollo🔗

Librerías y paquetes de programación para construir aplicaciones, análisis y flujos de datos.

Iconos de lenguaje: 🐍 Python · 🟨 JavaScript / TypeScript · ⚙️ C / C++ · 🦀 Rust · ☕ Java

Manipulación vectorial, geometría y análisis base🔗

  • 🐍 GDAL / OGR (Python) — Bindings oficiales del módulo osgeo para acceso completo a la librería GDAL/OGR.
  • 🐍 pyogrio — Interfaz vectorial rápida construida sobre GDAL/OGR con soporte directo de DataFrames.
  • 🐍 Shapely — Manipulación y análisis de geometrías vectoriales 2D y 3D en Python (basado en GEOS).
  • 🐍 GeoPandas — Extensión geoespacial de pandas para operar con GeoDataFrames y geometrías vectoriales.
  • 🐍 Fiona — Lectura y escritura ordenada de datos vectoriales en Python basada en OGR.
  • 🟨 Turf.js — Colección modular de algoritmos y análisis geoespacial espacial sobre GeoJSON en navegador y Node.js.
  • 🟨 JSTS — Port a JavaScript de JTS Topology Suite para predicados espaciales y operaciones de geometría.
  • ☕ GeoTools — Toolkit estándar de Java para manipulación de datos espaciales, motor base de GeoServer.
  • ⚙️ MDAL — Librería C++ para lectura y procesado de mallas multidimensionales y series temporales (usada por QGIS).
  • ⚙️ SFCGAL — Librería C++ de geometría 3D sobre CGAL; backend del soporte 3D avanzado de PostGIS.
  • 🟨 wkx — Parseo y serialización bidireccional de formatos WKT y WKB en JavaScript.
  • 🟨 shpjs — Librería para parsear archivos Shapefile (.zip, .shp, .dbf) en el navegador o backend.
  • 🟨 TopoJSON — Extensión de GeoJSON que codifica topología compartida, reduciendo drásticamente el tamaño de los datos.
  • 🟨 H3-js — Bindings de JavaScript para el sistema de indexación geoespacial hexagonal jerárquico H3 de Uber.

Ráster, teledetección y cubos de datos🔗

  • 🐍 Rasterio — Lectura, escritura y manipulación de datos ráster en Python basada en GDAL.
  • 🐍 rioxarray — Extensión geoespacial que une Rasterio con arrays multidimensionales etiquetados de xarray.
  • 🐍 xarray — Estructuras de datos N-dimensionales etiquetadas, pilar del análisis climático y satelital.
  • 🐍 rasterstats — Cálculo de estadísticas zonales ráster a partir de geometrías vectoriales.
  • 🐍 pystac / pystac-client — Librerías en Python para interactuar con catálogos y APIs STAC de imágenes satelitales.
  • 🐍 stackstac — Transforma colecciones STAC en cubos de datos xarray con computación distribuida perezosa vía Dask.
  • 🐍 Satpy — Lectura, calibración y composición de imágenes procedentes de satélites meteorológicos y de observación.
  • 🐍 Open Data Cube — Arquitectura abierta para la gestión y análisis temporal de colecciones masivas de observación de la Tierra.
  • 🐍 TorchGeo — Librería de PyTorch con datasets, transformaciones y modelos preentrenados de deep learning geoespacial.
  • 🟨 geotiff.js — Parser e intérprete de metadatos e imágenes GeoTIFF/COG directamente en JavaScript.
  • 🟨 georaster — Estructura estandarizada para cargar y visualizar formatos ráster en aplicaciones web.

Geodesia, proyecciones y GNSS🔗

  • 🐍 pyproj — Interfaz de Python para la librería PROJ: proyecciones cartográficas y transformaciones geodésicas.
  • 🐍 PyGeodesy — Funciones trigonométricas y cálculos geodésicos esféricos y elipsoidales en Python puro.
  • 🐍 georinex — Lectura y parseo estructurado de ficheros GNSS RINEX (2, 3 y 4) a DataFrames.
  • 🐍 gnss-lib-py — Marco modular en Python para procesar, visualizar y resolver estimaciones de posición GNSS.
  • 🟨 proj4js — Puerto de PROJ a JavaScript para cálculo de proyecciones y transformación de coordenadas en cliente web.

Nubes de puntos, fotogrametría y 3D🔗

  • 🐍 laspy — Lectura, creación y edición de nubes de puntos LiDAR en formato LAS y LAZ desde Python.
  • 🐍 Open3D — Librería moderna para el procesado, registro, filtrado y renderizado de geometrías 3D y nubes de puntos (Python/C++).
  • 🐍 py3dtiles — Generación, lectura y conversión de conjuntos 3D Tiles y nubes de puntos desde Python.
  • 🐍 triangle-splatting — Implementación oficial de Triangle Splatting en Python/CUDA para optimización y renderizado de radiance fields con triángulos.
  • 🐍 gsplat — Librería abierta acelerada en CUDA para rasterización y optimización de 3D Gaussian Splatting (base de nerfstudio y pipelines 3D).
  • 🟨 gltf-pipeline — Optimización, compresión Draco y conversión de modelos glTF/GLB para su integración en tilesets 3D Tiles.
  • 🐍 pycolmap — Bindings oficiales de Python para el pipeline de reconstrucción de COLMAP.
  • 🐍 OpenSfM — Pipeline de Structure-from-Motion en Python (Mapillary) para reconstrucción fotogramétrica a gran escala.
  • 🐍 pyRANSAC-3D — Ajuste y detección de primitivas geométricas 3D (planos, cilindros, esferas) en nubes de puntos con RANSAC.
  • ⚙️ OpenCV — Librería de visión artificial de referencia (módulo calib3d para calibración con tableros CharuCo/Checkerboard, estéreo y homografías).
  • ⚙️ Ceres Solver — Optimizador no lineal de Google, motor de Bundle Adjustment y ajuste de haces en COLMAP y herramientas de SfM.
  • ⚙️ OpenMVG — Librería C++ para geometría de vistas múltiples (Structure-from-Motion).
  • ⚙️ OpenMVS — Librería C++ para Multi-View Stereo, densificación y generación de mallas texturizadas 3D.
  • ⚙️ TheiaSfM — Librería C++ para Structure-from-Motion escalable y rápida con ajuste de haces multithreading.
  • ⚙️ GTSAM — Factor graphs en C++ y Python para SLAM visual, estimación de trayectoria y calibración de sensores.
  • ⚙️ MicMac — Suite fotogramétrica libre desarrollada por el IGN francés (ENSG) para investigación y aplicaciones de precisión.
  • ⚙️ PCL — Point Cloud Library — Librería clásica de algoritmos 2D/3D para visión artificial y nubes de puntos.
  • ⚙️ OSSIM — Librería C++ de alto rendimiento para procesamiento fotogramétrico y corrección de imágenes de teledetección.

Visualización interactiva y cartografía temática🔗

  • 🟨 Deck.gl — Framework de visualización geoespacial acelerado por GPU (WebGL) para conjuntos de datos masivos.
  • 🟨 Terra Draw — Motor de dibujo y edición vectorial de geometrías compatible con Leaflet, MapLibre, OpenLayers y Google Maps.
  • 🟨 geojson-vt — Generador de teselas vectoriales en cliente al vuelo a partir de grandes volúmenes de GeoJSON.
  • 🟨 PMTiles — Implementación JS/TS del formato de archivo único para visualización de pirámides de teselas sin servidor.
  • 🟨 GeoStyler — Librería e interfaz gráfica para conversión y edición de estilos cartográficos (SLD, OpenLayers, MapLibre).
  • 🐍 Cartopy — Librería de Python para producción de mapas temáticos de alta calidad cartográfica sobre Matplotlib.
  • 🐍 leafmap — Paquete de Python para análisis y visualización interactiva de datos geoespaciales con múltiples backends.
  • 🐍 geemap — Paquete de Python para análisis interactivo y cartografía con Google Earth Engine.
