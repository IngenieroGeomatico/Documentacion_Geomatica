Documentación Geomática

Punto de acceso a documentación, software de fuente abierta y recursos útiles para la Topografía y la Geomática.

Punto de acceso a documentación, software de fuente abierta y recursos útiles para la Topografía y la Geomática. El objetivo es ayudar a los Ingenieros en Geomática y Topografía a encontrar recursos necesarios para nuestra bonita profesión.

Este repositorio es un directorio vivo y curado de enlaces de interés en el ámbito de la Ingeniería Geomática. El propio README.md es la fuente desde la cual se genera automáticamente la web publicada en GitHub Pages.

Documentación y referencia

Manuales, normativa y material formativo de referencia.

  • OSGeo — Open Source Geospatial Foundation — Fundación que agrupa los principales proyectos geoespaciales libres.
  • Documentación oficial de QGIS — Manual de usuario, guía de formación y manual de PyQGIS.
  • Documentación de GDAL/OGR — Librería de referencia para lectura/escritura de datos ráster y vectoriales.
  • PROJ — Transformaciones de coordenadas — Biblioteca para proyecciones y transformaciones de sistemas de referencia.
  • EPSG — Registro EPSG de sistemas de referencia de coordenadas (CRS).
  • Instituto Geográfico Nacional (IGN España) — Cartografía oficial, geodesia, nivelación y redes GNSS.
  • Centro Nacional de Información geográfica (CNIG) — Centro de descargas de datos geográficos oficiales de España.
  • OGC — Open Geospatial Consortium — Estándares abiertos geoespaciales (WMS, WFS, WMTS, GeoPackage, etc.).
  • OGC APIs — Nueva familia de estándares OGC basados en OpenAPI/REST (Features, Tiles, Maps, Coverages…), el futuro de los servicios geoespaciales.
  • Referencia de funciones PostGIS — Documentación oficial de las funciones espaciales SQL (ST_*) y operadores de PostGIS.
  • Especificación 3D Tiles (OGC) — Estándar abierto para streaming y renderizado de datos geoespaciales 3D masivos (mallas, nubes de puntos, edificios).

Software de fuente abierta

Herramientas libres para adquisición, procesado, análisis y publicación de datos geoespaciales.

SIG de escritorio y campo

  • QGIS — Sistema de Información Geográfica de escritorio, el estándar libre de facto.
  • GRASS GIS — SIG con potente análisis ráster, vectorial y geoespacial.
  • SAGA GIS — Análisis geocientífico, especialmente modelos digitales del terreno.
  • gvSIG Desktop — SIG de escritorio con fuerte comunidad hispanohablante.
  • QField — Aplicación móvil basada en QGIS para la captura y edición de datos geoespaciales en campo.

Geodesia, GNSS y topografía

  • RTKLIB — Posicionamiento GNSS de precisión (RTK, PPP) de código abierto.
  • GNSS-SDR — Receptor GNSS definido por software.
  • Emlid / documentación RTK — Referencia sobre flujos de trabajo RTK/PPK.
  • GNU Gama — Ajuste riguroso de redes geodésicas y topográficas por mínimos cuadrados (línea de comandos).

Fotogrametría, LiDAR y nubes de puntos

  • OpenDroneMap (ODM / WebODM) — Fotogrametría con drones de código abierto.
  • CloudCompare — Edición y comparación de nubes de puntos 3D y mallas.
  • PDAL — Point Data Abstraction Library — Procesado de nubes de puntos LiDAR.
  • LAStools (open components) — Herramientas para datos LiDAR en formato LAS/LAZ.
  • Meshroom (AliceVision) — Reconstrucción 3D fotogramétrica.

Librerías

  • COLMAP — Pipeline de Structure-from-Motion (SfM) y Multi-View Stereo (MVS) de propósito general, con bindings de Python (pycolmap).
  • OpenMVG — Librería de geometría de vistas múltiples centrada en pipelines de SfM (C++).
  • OpenMVS — Librería de Multi-View Stereo para reconstrucción densa y mallado (C++), complemento habitual de COLMAP.
  • MicMac — Suite fotogramétrica completa de reconstrucción 3D del IGN francés (C++).
  • Open3D — Librería moderna de procesado de datos 3D, mallas y nubes de puntos (Python/C++).
  • PCL — Point Cloud Library — Librería de referencia para procesado de nubes de puntos 2D/3D (C++).
  • laspy — Lectura y escritura de nubes de puntos LiDAR en formato LAS/LAZ desde Python.

Bases de datos y servidores geoespaciales

  • PostGIS — Extensión geoespacial para PostgreSQL.
  • GeoServer — Servidor de datos geoespaciales (WMS/WFS/WCS).
  • MapServer — Servidor de mapas rápido y ligero.
  • pgRouting — Análisis de rutas sobre PostGIS.
  • pygeoapi — Servidor geoespacial en Python que implementa las OGC APIs (Features, Tiles, Coverages, Processes…).

Cartografía web y visualización

  • Leaflet — Librería JavaScript ligera para mapas interactivos.
  • OpenLayers — Librería JavaScript avanzada para mapas web.
  • MapLibre GL — Renderizado de mapas vectoriales por GPU (fork libre de Mapbox GL).
  • API-IDEE — API de la Infraestructura de Datos Espaciales de España para crear visualizadores de mapas interoperables.
  • CesiumJS — Librería JavaScript de código abierto para visualizadores 3D.

Librerías Python

Datos vectoriales y ráster (base)

  • GDAL (bindings de Python) — Wrapper oficial de Python para GDAL/OGR (módulo osgeo); acceso completo a la librería desde Python.
  • pyogrio — Wrapper vectorial rápido sobre GDAL/OGR para leer/escribir datos vectoriales en Python.
  • Shapely — Geometría vectorial en Python.
  • GeoPandas — Análisis de datos geoespaciales en Python.
  • Rasterio — Lectura/escritura de datos ráster en Python.
  • Fiona — Acceso a formatos vectoriales en Python.

Geodesia, coordenadas y GNSS

  • pyproj — Interfaz de Python para PROJ: proyecciones cartográficas y transformación de coordenadas.
  • PyGeodesy — Cálculos geodésicos elipsoidales y esféricos (distancias, rumbos, intersecciones) en Python puro.
  • georinex — Lectura rápida de ficheros RINEX (2, 3, 4) de observación y navegación GNSS.
  • gnss-lib-py — Marco modular para parsear, analizar y visualizar datos GNSS y estimar posición.

Teledetección y análisis ráster

  • rioxarray — Extensión geoespacial de Xarray que integra Rasterio con arrays multidimensionales etiquetados.
  • xarray — Arrays N-dimensionales etiquetados, base para el análisis de datos climáticos y de teledetección.
  • rasterstats — Estadísticas zonales de datos ráster a partir de geometrías vectoriales.
  • pystac / pystac-client — Trabajo con catálogos SpatioTemporal Asset Catalogs (STAC) para descubrir y acceder a datos de observación de la Tierra.
  • stackstac — Convierte ítems STAC en cubos de datos Xarray de carga perezosa con Dask.
  • Satpy — Lectura, manipulación y escritura de datos de satélites meteorológicos.

Cartografía temática y visualización

  • Cartopy — Procesado de datos geoespaciales y creación de mapas de calidad para publicación.
  • contextily — Añade mapas base de teselas de internet como fondo en gráficos.
  • mapclassify — Esquemas de clasificación para mapas coropléticos.
  • leafmap — Mapas interactivos ligeros para diversos formatos y proveedores de datos geoespaciales.
  • geemap — Análisis y cartografía interactiva específicos para Google Earth Engine.

Acceso a bases de datos espaciales

  • psycopg — Adaptador moderno de PostgreSQL para Python con soporte asyncio (sucesor de psycopg2); base para conectar con PostGIS.
  • SQLAlchemy — Toolkit SQL y ORM estándar de Python.
  • GeoAlchemy2 — Extensión geoespacial de SQLAlchemy para trabajar con bases de datos como PostGIS.

Librerías JavaScript

  • Turf.js — Motor modular de análisis geoespacial sobre GeoJSON en navegador y Node.js.
  • proj4js — Transformación de coordenadas entre sistemas de referencia y proyecciones (paquete npm proj4).
  • JSTS — Port a JavaScript de JTS Topology Suite para predicados espaciales y operaciones geométricas.
  • Deck.gl — Framework de alto rendimiento sobre WebGL para explorar y analizar grandes conjuntos de datos geoespaciales.
  • geojson-vt — Corte eficiente de GeoJSON masivo en teselas vectoriales al vuelo en el navegador.
  • Terra Draw — Dibujo y edición de geometrías compatible con Leaflet, MapLibre, OpenLayers y otros motores de mapas.
  • geotiff.js — Lectura y acceso a datos ráster GeoTIFF directamente en navegador o Node.js.
  • FlatGeobuf — Formato geoespacial binario de alto rendimiento para streaming y acceso aleatorio a grandes conjuntos de datos.
  • TopoJSON — Extensión de GeoJSON que codifica topología para reducir notablemente el tamaño de los ficheros.
  • H3-js — Port a JavaScript del sistema de indexación geoespacial hexagonal jerárquico H3 de Uber.
  • shpjs — Lectura de Shapefiles (SHP, DBF, PRJ) directamente en el navegador o Node.js.
  • georaster — Parsea formatos ráster (GeoTIFF, etc.) a una estructura unificada para mapas web.
  • PMTiles — Formato de archivo único para pirámides de teselas (ráster o vectoriales) servibles desde almacenamiento en la nube.
  • wkx — Parseo y serialización de geometrías en Well-Known Text (WKT) y Well-Known Binary (WKB).

3D Tiles y visualización 3D

  • 3D Tiles Tools (CesiumGS) — Herramientas oficiales para convertir, optimizar, procesar y analizar datos 3D Tiles.
  • Recursos y generadores de 3D Tiles — Catálogo oficial de herramientas y librerías para generar tilesets 3D Tiles.

Datos y recursos

Fuentes de datos abiertos y recursos de aprendizaje.

  • Directorio de Servicios de la IDEE — Catálogo de servicios web geoespaciales (WMS, WFS, WMTS, CSW, etc.) de la Infraestructura de Datos Espaciales de España, organizados por tipo.
  • OpenStreetMap — Cartografía colaborativa libre a escala mundial.
  • Copernicus / Sentinel Hub — Datos de observación de la Tierra del programa europeo Copernicus.
  • USGS EarthExplorer — Descarga de imágenes de satélite y modelos del terreno.
  • Natural Earth — Cartografía base de dominio público a varias escalas.
  • Wikidata — Base de conocimiento libre con millones de entidades geolocalizadas (coordenadas) consultables vía SPARQL; útil para enriquecer datos SIG con identificadores autoritativos.
  • GeoNames — Base de datos geográfica libre con más de 25 millones de topónimos y sus coordenadas, códigos administrativos y de país.
  • Awesome Geospatial — Lista curada de recursos geoespaciales.
